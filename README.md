# Локальный Telegram-бот для сна и выключения ПК

Бот работает на самом ПК через Telegram long polling. Он принимает команды только из личных чатов двух заданных `Telegram user ID` и умеет поставить один таймер сна или выключения, показать его и отменить.

Сейчас проект безопасен для разработки: в `.env.example` установлен `DRY_RUN=1`. В этом режиме бот отвечает в Telegram, но **никогда не вызывает сон или выключение Windows**.

## Что умеет

- `Таймер` → сон или выключение → 30 минут, 1 час, 2 часа либо `HH:MM`.
- `Статус` и `Отмена` для единственной активной задачи.
- `Дополнительно` → `Сон сейчас` / `Выключить сейчас`; каждое действие требует подтверждения и получает 15 секунд на отмену.
- Текстовые команды: `/timer sleep 30m`, `/timer shutdown 1h`, `/at sleep 23:30`, `/status`, `/cancel`.

Свободный текст не передаётся в PowerShell или `shutdown.exe`. Выключение выполняется только фиксированной нефорсированной командой с нулевой задержкой; собственно ожидание ведёт бот. Это важно: `shutdown.exe /t N` при `N > 0` принудительно закрывает приложения, поэтому здесь он не используется.

## Быстрая проверка и автозапуск через `.bat`

После создания `.env` можно дважды щёлкнуть `setup-pc.bat`. Он сам найдёт Python 3.10+, проверит файлы проекта, компиляцию, unit-тесты, `.env` без соединения с Telegram, Планировщик задач и доступные режимы питания.

После успешной проверки появится отдельный выбор установки автозапуска. Он создаёт задачу только после подтверждения, не заменяет уже существующую `\PcPowerBot` и не запускает бота, Telegram, сон или выключение во время проверки. Без файла `.env` установка намеренно не предлагается: переменные текущего окна не переживут следующий вход в Windows.

## Настройка на тестовом ПК

1. Скопируйте `.env.example` в `.env` рядом с `bot.py`.
2. Впишите новый тестовый `BOT_TOKEN` и два числовых ID через запятую в `ALLOWED_USER_IDS`.
3. Оставьте `DRY_RUN=1`.
4. Запустите:

   ```powershell
   py -3.12 bot.py
   ```

5. Откройте с каждого разрешённого аккаунта личный чат с ботом и отправьте `/start`.

`@username` не подходит для allowlist. Нужны именно стабильные числовые ID. Команды из групп и от остальных аккаунтов игнорируются.

Для проверки без подключения к Telegram можно выполнить:

```powershell
py -3.12 bot.py --check
```

## Проверки исходников

```powershell
py -3.12 -m unittest discover -s tests -v
py -3.12 -m compileall -q .
```

Проект использует только стандартную библиотеку Python; `pip install` не нужен.

## Реальная активация

Не меняйте `DRY_RUN=0`, пока не завершена проверка с наблюдением за этим ПК. После явного решения на активацию следует сначала проверить отмену таймера и затем по одному действию сна/выключения при отсутствии несохранённой работы.

`DRY_RUN=0` разрешает ровно два фиксированных действия:

- сон через Windows Forms `Application.SetSuspendState`;
- выключение через `%SystemRoot%\System32\shutdown.exe /s /t 0` без `/f`.

Если сон на конкретном ПК не проходит, не включайте альтернативный произвольный PowerShell-код: оставьте выключение и отдельно исследуйте доступный режим сна.

## Автозапуск после входа в Windows

`setup-pc.bat` — предпочтительный путь для обычной проверки и установки. `install-autostart.ps1` не запускается автоматически и не заменяет существующую задачу. Когда сухой режим уже проверен, его можно вручную вызвать с абсолютным путём к `python.exe`:

```powershell
.\install-autostart.ps1 -PythonPath 'C:\Path\To\Python312\python.exe'
```

Скрипт создаёт задачу `\PcPowerBot` для текущего пользователя, срабатывающую после входа в Windows и с наименьшими правами. Она не работает до входа пользователя в систему.

Для удаления после отдельного решения используйте точный путь задачи:

```powershell
Unregister-ScheduledTask -TaskName 'PcPowerBot' -TaskPath '\' -Confirm:$false
```

## Перенос на мамин Windows 10 ПК

1. Скопируйте папку проекта без `.env` и `state.json`.
2. Создайте новый `.env` с отдельным рабочим токеном и теми же двумя разрешёнными ID.
3. Проверьте `powercfg /a`, оставьте `DRY_RUN=1` и проверьте меню, таймер, статус и отмену.
4. Только после отдельной проверки сна и выключения на этом ПК разрешайте `DRY_RUN=0` и создавайте задачу автозапуска.

## Ограничения

- ПК должен быть включён, подключён к интернету и иметь активный сеанс Windows.
- Удалённое пробуждение, перезагрузка, работа до входа в Windows, группы и самостоятельное добавление пользователей не реализованы.
- Один будущий таймер хранится в `state.json`. Просроченная задача после перезапуска бота удаляется и не выполняется.
- Реальная связь с Telegram, сон, выключение и автозапуск не были запущены во время разработки: для них нужны токен и отдельное контролируемое принятие.
