# PC Power Bot

Бот переводит один Windows-ПК в сон или выключает его по команде из Telegram. Команды принимаются только от двух заданных аккаунтов и только из личного чата.

## Быстрый старт

Нужны Python 3.10+, токен Telegram-бота и два числовых Telegram ID.

1. Если файла `.env` ещё нет, создайте его рядом с `bot.py`:

   ```powershell
   Copy-Item .env.example .env
   ```

2. Откройте `.env` и заполните:

   - `BOT_TOKEN` — токен бота;
   - `ALLOWED_USER_IDS` — два числовых ID через запятую;
   - `DRY_RUN=1` — первая безопасная проверка.

   Не публикуйте `.env`: в нём хранится токен.

3. Дважды щёлкните `setup-pc.bat`.

   Скрипт проверит Python, файлы проекта, настройки, Планировщик задач и доступные режимы питания. Затем:

   - при первой установке выберите `I`, затем `Y`;
   - если задача автозапуска уже есть, выберите `U`.

   После этого бот стартует без окна консоли.

4. Откройте личный чат с ботом и отправьте `/start`. Появится меню.

## Как пользоваться

`Таймер` → `Сон` или `Выключить ПК` → `Через` или `В точное время` → `Подтвердить`.

- `Через` — выберите 15/30 минут, 1/2 часа или `Указать самому`; например: `90 минут`.
- `В точное время` — напишите время в формате `HH:MM`, например `23:30`. Если это время уже прошло сегодня, бот выберет завтра.
- `Статус` показывает активный таймер, `Отмена` его снимает.
- В `Дополнительно` есть `Сон сейчас` и `Выключить сейчас`. После подтверждения остаётся 15 секунд на отмену.

## Тестовый и рабочий режим

| Значение | Результат |
| --- | --- |
| `DRY_RUN=1` | Бот отвечает, показывает меню и ведёт таймер, но не переводит ПК в сон и не выключает его. |
| `DRY_RUN=0` | После подтверждения бот действительно выполняет сон или выключение. |

После изменения `DRY_RUN` запустите `setup-pc.bat`: выберите `U` для существующей задачи автозапуска или `I` для новой.

## Обновление и удаление

После `git pull` изменения в `bot.py` и `pc_power_bot` работающий бот подхватывает сам после завершения текущего запроса к Telegram (при настройке по умолчанию — до 25 секунд). Изменение `.env` требует `U` через `setup-pc.bat`.

Чтобы остановить бота и удалить только задачу автозапуска, выполните в PowerShell:

```powershell
.\uninstall-autostart.ps1
```

Папка проекта, `.env` и `state.json` останутся на месте.

## Ограничения

- ПК должен быть включён, подключён к интернету, а в Windows должен быть выполнен вход пользователя.
- Работают только два ID из `ALLOWED_USER_IDS`; группы, другие аккаунты и `@username` не подходят.
- Одновременно возможен один будущий таймер.
- Удалённое пробуждение, перезагрузка и работа до входа в Windows не реализованы.
